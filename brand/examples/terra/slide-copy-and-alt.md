## Slide copy

Category: AI
Headline: OpenAI luncurkan GPT-6.1 Terra dengan harga API lebih rendah
Subheading / summary: Diklaim melampaui GPT-5.6 Terra untuk urusan kendali komputer, pengolahan visual, dan penulisan—dengan tarif separuh dari model Sol.

## Details

1. Harga. Harga API standar GPT-6.1 Terra adalah US\$1 per 1 juta token input, US\$0,05 untuk input yang di-cache, dan US\$5 untuk output. GPT-6.1 Sol dipatok US\$2/US\$0,10/US\$10, GPT-6 Astra US\$10/US\$1/US\$50, dan GPT-6 Luna US\$0,10/US\$0,01/US\$0,50. Dibandingkan GPT-5.6 Terra (US\$2/US\$0,20/US\$12), harga input Terra baru **50% lebih rendah dan harga output sekitar 58% lebih rendah**. Tarif ini berlaku hingga 272 ribu token input. \[D\]
2. Ketersediaan. OpenAI menyatakan GPT-6.1 Terra tersedia bagi seluruh pengguna **Plus, Pro, Enterprise, dan Edu** di ChatGPT Work dan Codex, serta melalui API dengan ID gpt-6.1-terra. Menurut OpenAI, kuota penggunaan di ChatGPT Work dan Codex menjangkau lebih banyak tugas dibandingkan GPT-5.6 Terra, dan jauh lebih banyak dibandingkan GPT-6.1 Sol atau GPT-6 Astra. \[A\]\[X2\]\[X4\]
3. Hasil uji OpenAI. Pada benchmark Agents' Last Exam, OpenAI melaporkan skor GPT-6.1 Terra **15 poin persentase di atas GPT-5.6 Terra** **dengan biaya sekitar sepertiganya**, setara GPT-6 Astra dengan harga per token sepersepuluhnya. Pada Terminal-Bench 4.0, model ini menyelesaikan 50,3% tugas, dibandingkan 21,5% untuk GPT-5.6 Terra. Angka-angka ini berasal dari pengujian OpenAI dan belum diverifikasi secara independen. \[A\]\[X3\]
4. Batas penggunaan dan keamanan. OpenAI menyarankan GPT-6.1 Sol atau GPT-6 Astra untuk **riset mendalam dan pemrograman kompleks**. Perusahaan juga menilai GPT-6.1 Terra memenuhi ambang "Critical" bidang keamanan siber dalam Preparedness Framework-nya, sehingga perlindungan yang dikembangkan untuk GPT-6 Astra tetap diterapkan. \[A\]\[C\]\[X2\]
